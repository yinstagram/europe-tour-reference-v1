# Europe Tour Reference V1 — Fact-check summary

Audit date: 2026-08-13 (Asia/Hong_Kong)

## Scope and truth model

The supplied seven-page Tour Specification was fully extracted and visually reviewed. The dates do not print a year; the complete weekday sequence matches 2026, so V1 uses 2026 as an inference and keeps written confirmation open.

- `verified`: a current official operator, government, venue, hotel, destination or official timetable supports the public fact.
- `source`: the travel-agent PDF says it; this does not prove a booking.
- `inference`: an operational route, buffer, cutoff or fallback derived from verified constraints.
- `unknown`: a dated exception, booking record, operator, choice or voucher is still missing.

Public opening information never promotes a ticket, room, table, flight or vehicle to “confirmed”.
